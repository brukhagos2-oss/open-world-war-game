# Frontier Ops

A lightweight, playable open-world combat game prototype in one HTML file, built with Three.js and vanilla JavaScript.

## Run locally

Open `index.html` in a modern browser. If your browser blocks JavaScript modules from `file://`, serve the folder with any static HTTP server (for example, `python -m http.server 8000`) and open `http://localhost:8000`.

## Controls

- **WASD / arrow keys** — move
- **Mouse** — aim (click the game to capture the pointer)
- **Left click** — fire
- **R** — reload
- **Shift** — sprint
- **Esc** — pause
- **Touchscreens** — left joystick to move, drag the open game view to look, and use Fire/Reload buttons

The game is a fictional, non-graphic arcade prototype. It uses procedural scenery and placeholder character models. Three.js, Google Fonts (if added later), and the title-screen photograph are loaded from external CDNs/Unsplash. GitHub Pages can serve it as a static site.
